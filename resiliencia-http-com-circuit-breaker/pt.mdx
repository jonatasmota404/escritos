Quando serviços distribuídos dependem uns dos outros de forma síncrona, uma lentidão pontual pode causar colapso sistêmico. O padrão **Circuit Breaker** existe para interromper chamadas fadadas ao fracasso antes que elas consumam todos os recursos da aplicação.

### Por que aplicar em produção?

- **Fail-Fast:** Não deixa conexões penduradas esperando timeout de 30 segundos.
- **Auto-recuperação:** Permite que o serviço externo instável se recupere sem receber uma enxurrada contínua de tráfego.
- **Degradação Elegante:** Facilita retornar dados de cache ou um fallback controlado para o usuário.
